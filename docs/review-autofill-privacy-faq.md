# 주문번호 자동 채움 — 개인정보 안내 문안

리뷰·반품·배송조회 화면에서 주문번호가 자동으로 채워지는 것에 대해 고객이 불안해할 때 쓰는 문안입니다.

## 실제로 저장되는 것 (사실 확인용)

| 키 | 값 | 저장 위치 |
|---|---|---|
| `brospick-last-order` | 주문번호 문자열 하나 (`app/order-complete/page.tsx:87`) | 고객 기기 브라우저 |
| `brospick-fp` | 랜덤 UUID (리뷰 좋아요 중복 방지용, 신원과 무관) | 고객 기기 브라우저 |
| `brospick-liked-reviews` | 좋아요 누른 리뷰 ID 목록 | 고객 기기 브라우저 |
| `brospick-cart` | 장바구니 담은 상품 | 고객 기기 브라우저 |

이름·전화번호·주소·결제정보는 저장하지 않는다. 전화번호는 어디에도 남지 않아 조회할 때마다 직접 입력해야 하고, 이것이 본인 확인 역할을 한다.

---

## 1) 주문번호 입력칸 밑에 넣을 짧은 한 줄

> 이전에 이 기기에서 주문하신 적이 있어 **주문번호만** 미리 채워뒀어요. 전화번호는 저장하지 않으니 직접 입력해주세요.

---

## 2) FAQ 한 칸

**Q. 제 주문번호가 자동으로 떠 있던데, 제 정보가 어딘가 저장돼 있는 건가요?**

아니요. 주문을 마치셨을 때 **주문번호 한 줄만** 손님 기기의 브라우저 안에 메모처럼 남겨둔 거예요. 매번 주문번호를 찾아 헤매지 않으셔도 되게 하려는 목적입니다.

- **저장되는 것:** 주문번호(예: `BP-20250209-1234`) 하나뿐입니다.
- **저장되지 않는 것:** 이름, 전화번호, 주소, 결제·카드 정보 — 전부 저장하지 않습니다.
- **어디에 있나요?** 브로스픽 서버가 아니라 **손님이 쓰시는 기기의 브라우저 안**에 있습니다. 브라우저 규칙상 브로스픽 사이트에서만 읽을 수 있고, 다른 사이트나 앱은 이 값을 볼 수 없어요.
- **그럼 주문번호만 있으면 내 주문이 보이나요?** 아니요. 조회하려면 **주문번호 + 주문할 때 쓰신 전화번호**가 둘 다 맞아야 합니다. 전화번호는 저장해두지 않기 때문에 화면에 자동으로 채워지지 않고, 매번 직접 입력하셔야 해요. 이게 본인 확인 역할을 합니다.
- **지우고 싶으면?** 브라우저 설정에서 사이트 데이터를 삭제하시거나, 시크릿 모드(비공개 브라우징)로 접속하시면 아무것도 남지 않습니다. 다른 기기나 다른 브라우저에서 열면 당연히 비어 있어요.

## 운영 메모 (고객에게 노출하지 않음)

- **"개인정보가 유출되지 않습니다" 같은 단정 문구는 쓰지 말 것.** 고객은 그 문장을 믿지 않고, 다른 사고가 났을 때 문구가 발목을 잡는다. 저장 항목을 그냥 나열하는 방식이 더 강하다.
- **공용 PC 이슈:** 가족·공용 기기에는 주문번호가 남는다. 다만 전화번호를 모르면 주문 내용을 볼 수 없어 실질적 위험은 작다. 더 확실히 하려면 리뷰 등록 후 `brospick-last-order`를 지우는 방법이 있으나, 재주문 시 자동 채움 편의가 사라진다.
- `brospick-last-order`는 배송조회(`app/tracking/page.tsx`), 반품(`app/returns/page.tsx`), 상품 상세의 리뷰 작성 링크(`app/apparel/[slug]/ProductDetailClient.tsx`)에서 쓴다. 삭제를 검토할 땐 세 곳 모두 영향받는다.
- **리뷰 작성 화면은 더 이상 주문번호를 쓰지 않는다.** 이름+전화번호로 조회하고, 목록에는 가린 주문번호(`BP-20250209-****`)만 내려간다 — 진짜 주문번호가 화면으로 나가면 그것이 배송조회의 열쇠가 되기 때문이다(`lib/utils/order-number.ts`). 따라서 위 FAQ의 자동 채움 설명은 배송조회·반품 화면에만 해당한다.
